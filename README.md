Calculadora de Fatorial.

Descrição:

Esse projeto simples foi desenvolvido em Python para calcular qualquer número em fatorial informado pelo usuário.
Esse projeto foi criado como um ecercício prático durante meus estudos em Análise e Desenvolvimento de Sistemas.

Para utilizá-lo, basta executar o código e informar o número. O programa vai retornar o fatorial daquele número.

Como o código funciona?

Este código utiliza a variável "numero" junto de int e input. Deste modo, a variável é um número inteiro e pode ser informado pelo usuário.
Foi determinado as variáveis "fatorial" e "contador" seriam igual a 1. Pois fatorial se inicia apartir da multiplicação por 1.
"while" foi usado para realizar multiplicações em loop até que ele fosse maior que o número inicial informado.
Durante o loop, o valor da fatorial é multiplicada pelo contador, armazenando o resultado anterior sucessivamente.
Assim que feito os cálculos com o número informado, o código usa "print" para que a variável "numero" tenha seu resultado exibido.
Obs.: o símbolo "!" é utilizado apenas para representar que o cálculo se refere a fatorial, deixando o código mais fiel ao cálculo matemático.
